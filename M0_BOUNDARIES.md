# Milestone 0 Boundaries

## Allowed in M0

- App bootstrap
- TypeScript and routing
- Navigation shell
- Placeholder screens
- Design tokens
- Reusable visual primitives
- Linting / formatting
- Platform launch verification

## Not allowed in M0

- Expo SQLite
- Drizzle ORM
- Account/category repositories
- Transaction records
- Balance calculations
- People/lending logic
- Reports calculations
- Cloud services
- AI / OCR
- Budgets / recurring entries
- Investments

## Gate to M1

Do not start M1 until the M0 acceptance checklist in `README.md` is fully green.
